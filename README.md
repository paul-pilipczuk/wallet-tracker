# Wallet Tracker

A React and TypeScript app built with Vite. This repository is the starting point for a UX portfolio project.

## Getting started

Use Node.js 26 (the version is recorded in `.nvmrc`), then install dependencies and start the development server:

```sh
npm install
npm run dev
```

## Checks

- `npm run typecheck` checks TypeScript types.
- `npm run lint` runs ESLint.
- `npm run build` checks types and creates a production build in `dist`.
- `npm run preview` serves the production build locally.
